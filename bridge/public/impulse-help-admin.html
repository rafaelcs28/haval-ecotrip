Setup (uma vez só):
  1. Google Cloud Console → APIs & Services → Enable Google Drive API.
  2. Credentials → Create OAuth Client ID → Web application.
  3. Authorized redirect URI: carregando…
  4. Copia Client ID + Client Secret pro .env do bridge:
    GOOGLE_OAUTH_CLIENT_ID=...
    GOOGLE_OAUTH_CLIENT_SECRET=...
  5. Reinicia o bridge (pm2 restart bridge) e clica "Conectar Google Drive" acima.
