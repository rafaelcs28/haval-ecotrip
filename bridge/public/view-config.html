🔐 Conta & Segurança
Senha
Nova senha
Confirmar nova senha
Mínimo 4 caracteres. Você precisará logar novamente após trocar.
Autenticação em 2 etapas (TOTP)
2FA
Código de 6 dígitos no login (Google Authenticator, Authy)
Quando ativo, novos dispositivos precisam do código. Sessões logadas continuam funcionando.
Login biométrico (Face ID / Touch ID / fingerprint)
Depois de cadastrado, o login nesse dispositivo pode ser feito direto pela biometria. Senha+2FA continuam como fallback.
Login biométrico
Cadastro de biometria não é suportado dentro do app nativo (limitação iOS WKWebView). O app já está autenticado pelo token salvo — não precisa cadastrar passkey aqui. Pra usar passkey, abre o PWA standalone do Safari.
