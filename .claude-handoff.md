# Handoff — Haval Ecotrip Impulse

Documento pra continuar a sessão em outra máquina. Última atualização: 2026-05-16.

---

## 1. Contexto do projeto

**Haval Ecotrip Impulse**: app Android pro multimídia do Haval H6 PHEV + PWA no iPhone, conectados via MQTT bridge no Mac mini.

- **App Android** (`/app/src/main/...`): roda no head unit do carro, lê dados do barramento via Shizuku/CarDataManager (privilégio root). Publica via MQTT pra um broker.
- **Bridge Node.js** (`/bridge/server.js`): roda no Mac mini, consome MQTT, mantém `state` em memória, serve PWA via HTTP+WebSocket. Persiste em `state.json`, `events.json`, `trips.json`, `charges.json`.
- **PWA iPhone** (`/bridge/public/`): mostra dashboard ao vivo, log de eventos, histórico de viagens/recargas, ações remotas (lock/unlock/AC).
- **Home Assistant na VM (UTM no Mac mini, 192.168.64.3)**: tem integração GWM Brasil como custom_component MQTT-based — publica entidades do carro direto no broker.

**Idioma do projeto**: pt-BR (commits, comentários, UI).

## 8. Decisões importantes + rationale

### Migração HA (penúltimo passo)

- **Por que**: o barramento via Shizuku emitia valores ruidosos em rajadas (até 6+ leituras erradas consecutivas), gerando eventos espúrios. User propôs: HA já tem essas chaves via integração oficial GWM Brasil (cloud).
- **Como**: integração GWM publica `gwmbrasil_<chassi>/<id>/state` no mesmo broker. Bridge subscreve. HA é fonte de verdade pra body/lock/etc.
- **Caveat descoberto**: a integração só publica COM retain os tópicos que mudam frequentemente (alertas, agendamento). Os estáveis (doors/lock/etc.) só publicam ao MUDAR. Solução: REST `/api/states` no boot pra estado inicial.

### O que manter no app vs HA

- **App**: speed, RPM, motor power, fuel level, inside/outside temp, HVAC details, seat vent
  - User explicitamente pediu fuel e inside_temp do app ("dados divergentes, mais precisos do barramento")
  - speed/RPM/power: HA não expõe
  - HVAC details: HA só tem AC binário; o granular (temp/fan_speed/sync/auto/cycle) é do app
- **HA**: tudo passivo (doors/lock/AC binary/windows/sunroof/tires/SOC/12V/odo/autonomia/charging_state/address)

### Fast lane (v5.2-v5.6)

- Speed/RPM/power mudam continuamente durante condução. Publish a 1s era visivelmente lerdo. Fast lane publica só essas 4 chaves a 40 Hz (25ms) sem mexer no snapshot full.
- Drop-if-in-flight + executor dedicado evita backlog quando rede engasga.

### Edição manual de recargas

- User reportou recargas com SOC/kWh errados (falha no barramento durante a recarga). Endpoint `PATCH /api/charges/:ts/edit` permite override de `soc_start`, `soc_end`, `energy_kwh`, `duration_sec`.
- Armazenado em `charges.json` no campo `manual_overrides`. PWA mostra ícone ✏️ nos campos editados + opção de reverter.
- MQTT merge logic preserva `manual_overrides` quando Android re-publica histórico (não sobrescreve).

## 9. Comandos importantes

### Bridge / Mac mini

```bash
# Acessar bridge
cd ~/haval-ecotrip/bridge

# Carregar credenciais MQTT na shell (sempre que abrir novo terminal)
eval "$(grep -E '^MQTT_(USER|PASS)=' .env)"

# Atualizar bridge com últimos commits
git pull && pm2 restart ecotrip-bridge

# Recarregar env do .env (pm2 cacheia, restart simples não pega)
pm2 delete ecotrip-bridge && pm2 start server.js --name ecotrip-bridge && pm2 save

# Monitorar logs
pm2 logs ecotrip-bridge --raw

# Inspecionar tópicos MQTT
mosquitto_sub -h 192.168.64.3 -u "$MQTT_USER" -P "$MQTT_PASS" -t '#' -v -W 30
mosquitto_sub -h 192.168.64.3 -u "$MQTT_USER" -P "$MQTT_PASS" -t 'gwmbrasil_lgwffva55sh931315/+/state' -v -W 30

# Verificar state em disco (atualizado 2s depois de cada msg do app)
cat ~/haval-ecotrip/bridge/state.json | python3 -m json.tool | grep -E 'lock_state|door|window'

# Limpar events.json (lixo de eventos espúrios)
pm2 stop ecotrip-bridge && mv events.json events.json.bak && echo '[]' > events.json && pm2 start ecotrip-bridge
```

## 11. Issues conhecidos / armadilhas

- **`/api/state` requer auth**: precisa header `Authorization: Bearer <BRIDGE_TOKEN>`. Pra inspeção rápida, usar `state.json` em disco.
- **pm2 cacheia env**: alterações no `.env` não são picked up por `pm2 restart`. Tem que fazer `pm2 delete` + `pm2 start`.
- **`mosquitto_sub -t '#'` pode ser bloqueado por ACL** do broker pra wildcard total — use prefixos específicos.
- **HA OS não tem SSH na porta 22 por default** — precisa do Add-on "Advanced SSH & Web Terminal" pra liberar.
- **Service worker do PWA agressivo** — depois de mudanças em `bridge/public/app.js`, hard refresh + unregister SW no iPhone.
- **Token JWT do HA está no .env e foi compartilhado em chat** — válido até 2036; rotacionar quando quiser via HA UI → Perfil → Long-Lived Access Tokens.
