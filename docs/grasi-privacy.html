Grasi Recarga

Última atualização: 4 de junho de 2026

O Grasi Recarga é um aplicativo pessoal para acompanhar o estado da bateria e as sessões de recarga de um veículo BYD Song Pro. Ele se conecta exclusivamente a um servidor privado, controlado pelo próprio usuário, para exibir os dados do veículo.

Política de Privacidade

Levamos a sua privacidade a sério. Em resumo:

  • Não coletamos dados pessoais. O aplicativo não cria perfis, não usa rastreadores de publicidade e não vende nem compartilha informações com terceiros.
  • Os dados ficam no seu servidor. As informações do veículo (carga da bateria, potência de recarga, tempo restante, histórico de sessões) são lidas de um servidor privado do próprio usuário e exibidas no aplicativo. Não são armazenadas em servidores nossos.
  • Autenticação. O acesso ao servidor usa um token de autenticação guardado de forma segura no dispositivo. Esse token nunca é compartilhado com terceiros.
  • Notificações. Para enviar alertas (ex.: recarga concluída), um identificador de notificação do dispositivo é registrado no servidor privado do usuário. Ele é usado apenas para entregar essas notificações.
  • Sem analytics de terceiros. O aplicativo não integra SDKs de análise ou rastreamento de terceiros.

Exclusão de dados

Como os dados residem no servidor privado do usuário, basta remover o aplicativo e/ou revogar o token de acesso no servidor para encerrar qualquer comunicação.
